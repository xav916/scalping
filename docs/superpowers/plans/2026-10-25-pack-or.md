# Pack « or » — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** trois skills versionnées dans le dépôt qui *refusent* — un état d'armement qui ne peut pas rendre « OK » sans savoir, une pré-inscription sans critère falsifiable, un verdict dont le rejeu n'est pas validé.

**Architecture:** quatre unités. Un module commun d'analyse de sections markdown (accent-insensible, car les titres du dépôt varient), puis une skill par moment de la méthode. Chaque script sépare ce qui **collecte** (réseau, git, SSH) de ce qui **juge** (pur), et seul le juge est testé — c'est ce qui rend les tests exécutables sans réseau ni production.

**Tech Stack:** Python 3 **stdlib seule** (`re`, `json`, `hashlib`, `subprocess`, `unicodedata`, `argparse`), `pytest` pour les tests, `git` en sous-processus. Aucune dépendance à installer.

**Spec:** `docs/superpowers/specs/2026-10-25-pack-or-design.md`

## Global Constraints

- **Stdlib seule.** Aucun `pip install`, ni ici ni sur l'EC2.
- **Lecture seule sur la production.** Aucun `POST`, aucun `kill`, aucune écriture. Jamais d'armement ni de désarmement.
- **Aucun commit** par les skills. Le commit reste un geste humain.
- **Fail-closed et bavard.** Ne pas pouvoir vérifier ⇒ **code 1 avec la raison**. ⛔ Jamais code 0 sur une information manquante, inconnue ou datée du futur.
- **Chaque test a son jumeau négatif** : la même fixture portant le défaut, qui doit provoquer le refus. Leçon du 11/10 — *un test insensible au défaut ne prouve rien*.
- Tests exécutés par `python -m pytest .claude/skills` — **sans réseau ni base de production**.
- Les messages utilisateur sont en **français**, sans accents dans le code source (convention du dépôt).

## Ce que ce plan PRÉCISE par rapport au spec

Le spec exige « un critère à seuils numériques explicites, pas de la prose ». Deviner une intention dans de la prose française serait fragile et silencieusement faux. Le plan impose donc un **bloc machine** en commentaire HTML dans la pré-inscription :

```
<!-- CRITERE-MACHINE
admission: t > +2
rejet: t < -2
validite: abs(ecart_par_trade) < 0.50
cellules: 5
plafond: permutation_p95
-->
```

🔑 C'est la leçon de `trader-skill` : son contrôleur lit un `config.json`, pas une phrase. ⚠️ **Conséquence assumée** : les pré-inscriptions antérieures au 25/10 n'ont pas ce bloc et seront refusées par `or-preinscription`. C'est voulu — la skill contraint ce qu'on écrit **désormais**, elle ne réécrit pas le passé. `or-verdict` le dira explicitement (`bloc machine absent : pre-inscription anterieure a la convention`) au lieu de planter.

# .claude/skills/or_commun/sections.py
"""Analyse des sections d'une pre-inscription ou d'un verdict.

Les titres du depot VARIENT : releve du 25/10, le critere apparait sous six
formes ("## LE CRITERE", "..., POSE AVANT DE REGARDER", "..., pose d'avance")
et les predictions sous sept, avec et sans accents. On compare donc sur une
forme NORMALISEE, jamais sur la chaine exacte.
"""
from __future__ import annotations

import re
import unicodedata

_MACHINE = re.compile(r"<!--\s*CRITERE-MACHINE\s*(.*?)-->", re.S)
_TITRE = re.compile(r"^(#{1,6})\s+(.*)$")
_PREDICTION = re.compile(r"^\s*(\d+)\.\s+\S")


def normaliser(texte: str) -> str:
    """Minuscules, sans accents, sans ponctuation decorative."""
    sans_accent = "".join(
        c for c in unicodedata.normalize("NFD", texte)
        if unicodedata.category(c) != "Mn")
    return re.sub(r"[^a-z0-9 ]+", " ", sans_accent.lower()).strip()


def section(markdown: str, mot_cle: str) -> str | None:
    """Le corps de la premiere section dont le titre contient `mot_cle`.

    Rend `None` si aucun titre ne correspond -- l'appelant DOIT traiter ce cas
    comme un refus, jamais comme une section vide.
    """
    cle = normaliser(mot_cle)
    lignes = markdown.splitlines()
    debut = niveau = None
    for i, ligne in enumerate(lignes):
        m = _TITRE.match(ligne)
        if not m:
            continue
        if debut is None:
            if cle in normaliser(m.group(2)):
                debut, niveau = i + 1, len(m.group(1))
            continue
        if len(m.group(1)) <= niveau:
            return "\n".join(lignes[debut:i]).strip()
    if debut is None:
        return None
    return "\n".join(lignes[debut:]).strip()


def compter_predictions(markdown: str) -> int:
    """Le nombre de predictions NUMEROTEES de la section des predictions.

    Les puces ne comptent pas : une prediction doit etre numerotee pour etre
    citable dans un verdict ("ma prediction n 2 est fausse").
    """
    corps = section(markdown, "prediction")
    if corps is None:
        return 0
    return sum(1 for ligne in corps.splitlines() if _PREDICTION.match(ligne))


def bloc_machine(markdown: str) -> dict | None:
    """Le bloc `CRITERE-MACHINE`, ou `None` s'il est absent.

    Format `cle: valeur`, une par ligne. Deviner un seuil dans de la prose
    francaise serait fragile et silencieusement faux : on exige un bloc lisible
    par une machine, comme le `config.json` de trader-skill.
    """
    m = _MACHINE.search(markdown)
    if not m:
        return None
    out: dict = {}
    for ligne in m.group(1).splitlines():
        if ":" not in ligne:
            continue
        cle, _, valeur = ligne.partition(":")
        cle, valeur = cle.strip(), valeur.strip()
        if cle and valeur:
            out[cle] = valeur
    return out or None
```

# .claude/skills/or-preinscription/preinscrire.py
"""Refuse une mesure dont le critere n'est pas falsifiable.

Nee de deux fautes en trois jours : les 12/10 et 14/10, mon critere n'avait
qu'une condition « pas significativement pire », franchie trivialement par
tout ce qui est proche de zero. Une condition de non-degradation ne peut
JAMAIS servir de condition d'ADMISSION.

Et du 14/10 : sans plafond par permutation, SEPT cellules auraient « passe »
a t = 2 -- le hasard seul en fait passer autant.
"""
from __future__ import annotations

import argparse
import pathlib
import subprocess
import sys

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent))
from or_commun import sections  # noqa: E402

MINIMUM_PREDICTIONS = 3


def valider(markdown: str, anteriorite: bool | None) -> list[str]:
    """La liste des manques. Vide = la pre-inscription tient."""
    manques: list[str] = []

    if sections.section(markdown, "critere") is None:
        manques.append("aucune section critere")

    bloc = sections.bloc_machine(markdown)
    if bloc is None:
        manques.append("bloc machine CRITERE-MACHINE absent : un seuil devine "
                       "dans de la prose serait silencieusement faux")
    else:
        if "admission" not in bloc:
            manques.append("aucune condition d'admission : « pas "
                           "significativement pire » n'en est jamais une "
                           "(fautes des 12/10 et 14/10)")
        if "validite" not in bloc:
            manques.append("aucune condition de validite du rejeu, distincte "
                           "du critere")
        try:
            cellules = int(bloc.get("cellules", "1"))
        except ValueError:
            cellules = 2  # illisible => on exige le plafond, fail-closed
            manques.append("nombre de cellules illisible")
        if cellules > 1 and "plafond" not in bloc:
            manques.append("plafond par permutation absent pour %d cellules : "
                           "le 14/10, sept cellules auraient passe a t=2"
                           % cellules)

    n = sections.compter_predictions(markdown)
    if n < MINIMUM_PREDICTIONS:
        manques.append("%d prediction(s) numerotee(s), il en faut %d"
                       % (n, MINIMUM_PREDICTIONS))

    if anteriorite is None:
        manques.append("impossible de PROUVER que la pre-inscription precede "
                       "le banc (git muet, ou banc non suivi)")
    elif anteriorite is False:
        manques.append("le banc est anterieur a sa pre-inscription")

    return manques


def _premier_commit(chemin: str) -> str | None:
    try:
        out = subprocess.run(
            ["git", "log", "--diff-filter=A", "--format=%ct", "--", chemin],
            capture_output=True, text=True, timeout=20)
    except Exception:
        return None
    lignes = [l for l in out.stdout.splitlines() if l.strip()]
    return lignes[-1] if lignes else None


def anteriorite_git(preinscription: str, banc: str | None) -> bool | None:
    """`True` si la pre-inscription precede le banc, `None` si indeterminable.

    ⛔ Un banc non suivi par git rend `None`, pas `True` : on ne peut pas
    prouver qu'il est posterieur.
    """
    if banc is None:
        return None
    a, b = _premier_commit(preinscription), _premier_commit(banc)
    if a is None or b is None:
        return None
    return int(a) <= int(b)


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("preinscription")
    ap.add_argument("--banc", default=None)
    a = ap.parse_args(argv)

    try:
        texte = pathlib.Path(a.preinscription).read_text(encoding="utf-8")
    except Exception as e:  # noqa: BLE001
        print("ECHEC : pre-inscription illisible (%s)" % e)
        return 1

    manques = valider(texte, anteriorite_git(a.preinscription, a.banc))
    if not manques:
        print("OK : la pre-inscription tient. Le banc peut etre ecrit.")
        return 0
    print("REFUS : %d manque(s)\n" % len(manques))
    for m in manques:
        print("  - " + m)
    return 1


if __name__ == "__main__":
    sys.exit(main())
```

"""Refuse de publier un verdict dont le rejeu n'est pas valide.

Le 25/10, deux mesures et deux issues opposees :
  - le 12/10 : le rejeu reproduisait la journee sur TROIS cibles -> publiable ;
  - le hors echantillon : ecart -0,5731 EUR/trade contre une barre de 0,50
    posee d'avance -> NON CONCLUANT, et c'est ce calcul qui m'a arrete.

🔑 Une barre calculee arrete ; une bonne intention ecrite, non.
"""
from __future__ import annotations

import argparse
import hashlib
import json
import pathlib
import subprocess
import sys

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parent.parent))
from or_commun import sections  # noqa: E402

REQUIS = ("n", "t", "ecart_par_trade", "valide")
PUBLIABLE, REFUS = "PUBLIABLE", "NE PAS PUBLIER"


def _seuil(expression: str, defaut: float) -> float:
    """Le nombre d'une expression de seuil, ou `defaut`."""
    import re
    m = re.search(r"[-+]?\d+(?:[.,]\d+)?", expression or "")
    return float(m.group(0).replace(",", ".")) if m else defaut


def juger(resultat: dict, bloc: dict | None,
          critere_intact: bool | None) -> tuple[str, list[str]]:
    """`(decision, raisons)`. `decision` vaut PUBLIABLE ou NE PAS PUBLIER."""
    raisons: list[str] = []

    if bloc is None:
        raisons.append("bloc machine absent : pre-inscription anterieure a la "
                       "convention du 25/10, ou critere non machine-lisible")
        return REFUS, raisons

    if critere_intact is None:
        raisons.append("impossible de COMPARER l'empreinte du critere a sa "
                       "version commitee")
        return REFUS, raisons
    if critere_intact is False:
        raisons.append("critere REECRIT apres coup : son empreinte ne "
                       "correspond plus a la version commitee")
        return REFUS, raisons

    manquants = [c for c in REQUIS if c not in resultat]
    if manquants:
        raisons.append("le banc n'emet pas %s : la condition de validite n'est "
                       "pas calculable" % ", ".join(manquants))
        return REFUS, raisons

    barre = _seuil(bloc.get("validite", ""), 0.50)
    ecart = abs(float(resultat["ecart_par_trade"]))
    if not resultat["valide"] or ecart >= barre:
        raisons.append("condition de validite NON tenue : ecart %.4f contre "
                       "une barre de %.2f" % (ecart, barre))
        return REFUS, raisons

    t = float(resultat["t"])
    haut = _seuil(bloc.get("admission", "t > +2"), 2.0)
    bas = _seuil(bloc.get("rejet", "t < -2"), -2.0)
    if t > haut:
        raisons.append("admission franchie : t = %+.2f > %+.2f" % (t, haut))
    elif t < bas:
        raisons.append("rejet franchi : t = %+.2f < %+.2f" % (t, bas))
    else:
        raisons.append("indecidable : t = %+.2f reste entre %+.2f et %+.2f"
                       % (t, bas, haut))
    return PUBLIABLE, raisons


def empreinte_critere(chemin: str) -> bool | None:
    """Le critere sur le DISQUE est-il celui qui a ete commite ?

    `None` si la comparaison est impossible (git muet, fichier non suivi).
    """
    def _hash(texte: str) -> str | None:
        corps = sections.section(texte, "critere")
        if corps is None:
            return None
        return hashlib.sha256(corps.encode("utf-8")).hexdigest()

    try:
        disque = _hash(pathlib.Path(chemin).read_text(encoding="utf-8"))
        out = subprocess.run(["git", "log", "--diff-filter=A", "--format=%H",
                              "--", chemin],
                             capture_output=True, text=True, timeout=20)
        commits = [l for l in out.stdout.splitlines() if l.strip()]
        if not commits or disque is None:
            return None
        montre = subprocess.run(["git", "show", "%s:%s" % (commits[-1], chemin)],
                                capture_output=True, text=True, timeout=20)
        if montre.returncode != 0:
            return None
        return disque == _hash(montre.stdout)
    except Exception:  # noqa: BLE001
        return None


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("preinscription")
    ap.add_argument("resultat", help="le JSON emis par le banc")
    a = ap.parse_args(argv)

    try:
        texte = pathlib.Path(a.preinscription).read_text(encoding="utf-8")
        resultat = json.loads(pathlib.Path(a.resultat).read_text(encoding="utf-8"))
    except Exception as e:  # noqa: BLE001
        print("ECHEC : entree illisible (%s)" % e)
        return 1

    decision, raisons = juger(resultat, sections.bloc_machine(texte),
                              empreinte_critere(a.preinscription))
    print("=== %s" % decision)
    for r in raisons:
        print("  - " + r)
    return 0 if decision == PUBLIABLE else 1


if __name__ == "__main__":
    sys.exit(main())

import pathlib

REQUIS = ("rem002_allowed", "rem002_reason", "mirror_active", "pending",
          "pont_live", "pont_demo", "fingerprint_running", "fingerprint_armed")


def juger(etat: dict) -> tuple[int, list[str]]:
    """`(code_de_sortie, lignes)`. ⛔ Jamais 0 sur une information absente."""
    lignes: list[str] = []
    manquants = [c for c in REQUIS if c not in etat]
    if manquants:
        return 1, ["ECHEC : information absente, l'etat n'est pas determinable "
                   "-> %s" % ", ".join(manquants)]

    arme = bool(etat["rem002_allowed"])
    lignes.append("=== les 3 voies d'ordre")
    lignes.append("  1. _push_to_destination : %s (%s)"
                  % ("OUVERTE" if arme else "FERMEE", etat["rem002_reason"]))
    lignes.append("  2. _mirror_fill_to_live : %s"
                  % ("ACTIF" if etat["mirror_active"] else "inactif"))
    lignes.append("  3. file de l'EA         : %d PENDING" % int(etat["pending"]))
    lignes.append("")
    lignes.append("  equite %.2f EUR | %d position(s) ouverte(s)"
                  % (float(etat.get("equity") or 0), int(etat.get("positions") or 0)))
    lignes.append("  pont live : http=%s | pont demo : http=%s (informatif)"
                  % (etat["pont_live"], etat["pont_demo"]))

    if etat["fingerprint_running"] != etat["fingerprint_armed"]:
        lignes.append("  empreintes DIFFERENTES (%s / %s) : un rearmement "

                  % ("ARME" if arme else "DESARME"))
    return code, lignes
