# `or-porte` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une skill `or-porte` qui juge un lot de setups or contre les portes réelles de production, par destination, et rend `PASS`/`BLOCK` avec la raison, le correctif et une empreinte qui périme le verdict dès que le setup ou le code change.

**Architecture:** Le patron de `or-etat` : un **juge pur** testé (`juger()`), un **collecteur impur** non testé (`collecter()`, `ssh` + `docker exec`). Les verdicts de production viennent d'une **charge Python exécutée dans le conteneur** qui appelle `mt5_bridge._check_rejection` — la skill ne contient donc aucune copie d'une porte, et c'est structurel, pas seulement testé. Les quatre contraintes de lot sont calculées localement et étiquetées `origine: lot`.

**Tech Stack:** Python 3 bibliothèque standard uniquement (`json`, `hashlib`, `ast`, `pathlib`, `subprocess`, `argparse`). `pytest`. Aucune dépendance, aucune clé.

**Spec:** `docs/superpowers/specs/2026-10-29-or-porte-design.md` (commit `01c3a47`)

## Global Constraints

- ⛔ **Lecture seule, sans exception.** Aucun ordre, aucune écriture dans `trades.db`, aucun armement, aucun déploiement.
- ⛔ **Importer, jamais réimplémenter.** Toute clause de production est obtenue en appelant le code de production. Une clause recopiée est un défaut, y compris `asset_class_for`.
- ⛔ **Fail-closed partout.** Limite illisible, import impossible, empreinte indisponible : `BLOCK`, jamais `PASS`.
- 🔑 **Chaque clause déclare son origine**, `production` ou `lot`.
- ⛔ **REM-002 n'est ni contourné ni simulé.**
- Sorties utilisateur en français ; code et identifiants en anglais.
- Les onze champs lus par les portes, verbatim : `chaine`, `confidence_score`, `direction`, `entry_price`, `horizon`, `is_simulated`, `pair`, `pattern`, `shadow_system_id`, `stop_loss`, `verdict_blockers`.
- Codes de sortie : `0` tout passe · `1` au moins un `BLOCK` · `2` n'a pas pu juger.
- Convention de test du dépôt : `sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1]))` puis `import <module>`, et **fixtures en dicts Python portant de vraies valeurs de production**, avec la date du relevé en commentaire.

**Le contrat `brut`** — ce que la charge rend, et que `juger()` consomme. Il est fixé ici une fois pour toutes :

```json
{
  "fingerprint_running": "a4d9aedeee17",
  "verdicts": [
    {"i": 0, "destination": "admin_live", "reason_code": null, "classe": "metal",
     "admission": "AUTO_EXEC"}
  ],
  "limites": {
    "admin_live": {"max_correlated_positions": 3, "order_cooldown_sec": 0,
                   "max_risque_engage_pct": 5.0, "places_par_paire": 2}
  },
  "libelles": {"below_confidence": "Confiance < seuil"},
  "sans_libelle": ["pair_not_whitelisted"]
}
```

`i` est l'index du setup dans `lot["setups"]`. `reason_code: null` signifie que la production laisse passer. `classe` vient de `config.settings.asset_class_for` **calculée dans le conteneur**. Une valeur de `limites` à `null` signifie « illisible » et vaut `BLOCK`.

```python
"""Le lot de setups candidats : ce qu'on accepte, et son empreinte.

Les ONZE champs sont ceux que `_check_rejection` et ses aides lisent
reellement, obtenus par analyse AST transitive le 2026-10-29. Ni plus, ni
moins : hacher davantage perimerait des verdicts pour une modification sans
effet, hacher moins garderait vivant un verdict qu'une modification
materielle a invalide.
"""
from __future__ import annotations

import hashlib
import json

CHAMPS_PORTES = frozenset({
    "chaine", "confidence_score", "direction", "entry_price", "horizon",
    "is_simulated", "pair", "pattern", "shadow_system_id", "stop_loss",
    "verdict_blockers",
})

# `risk_pct` n'est lu par AUCUNE porte : il ne sert qu'a la contrainte de lot
# « risque engage », et il est donc exclu de l'empreinte.
CHAMPS_ADMIS = CHAMPS_PORTES | {"risk_pct"}


class ErreurLot(Exception):
    """Le lot n'est pas jugeable. Toujours en nommant le fautif."""


def empreinte_setup(setup: dict) -> str:
    """`sha256` tronque a 12, sur les ONZE champs seulement."""
    retenu = {k: setup.get(k) for k in sorted(CHAMPS_PORTES)}
    canon = json.dumps(retenu, sort_keys=True, separators=(",", ":"),
                       ensure_ascii=False, default=str)
    return hashlib.sha256(canon.encode("utf-8")).hexdigest()[:12]


def valider_lot(obj: dict) -> dict:
    """Rend le lot validé, ou leve `ErreurLot` en nommant le fautif."""
    if not isinstance(obj, dict):
        raise ErreurLot("le lot doit etre un objet JSON")
    dests = obj.get("destinations")
    if not isinstance(dests, list) or not dests:
        raise ErreurLot("`destinations` est absent ou vide")
    setups = obj.get("setups")
    if not isinstance(setups, list) or not setups:
        raise ErreurLot("`setups` est absent ou vide")

    for n, s in enumerate(setups):
        if not isinstance(s, dict):
            raise ErreurLot("setup #%d n'est pas un objet" % n)
        inconnues = sorted(set(s) - CHAMPS_ADMIS)
        if inconnues:
            raise ErreurLot(
                "setup #%d : cle(s) inconnue(s) %s -- seules %s sont admises, "
                "pour qu'on ne croie jamais qu'un champ decoratif a influence "
                "le verdict" % (n, ", ".join(inconnues),
                                ", ".join(sorted(CHAMPS_ADMIS))))
        manquants = sorted(CHAMPS_PORTES - set(s))
        if manquants:
            raise ErreurLot(
                "setup #%d : champ(s) requis manquant(s) %s -- les portes les "
                "lisent" % (n, ", ".join(manquants)))
    return {"destinations": list(dests), "setups": [dict(s) for s in setups]}
```

"""La charge Python executee DANS le conteneur de production.

Elle existe pour une seule raison : les portes lisent la configuration
d'environnement et la base de production. Les juger depuis un poste, avec
d'autres variables, rendrait un verdict qui ne decrit aucune realite.

⛔ Elle APPELLE `_check_rejection` et `asset_class_for`. Elle n'en recopie
aucune clause : une porte reimplementee divergerait a la premiere
modification et rendrait une reponse assuree et fausse.
"""
from __future__ import annotations

import json

_SOURCE = '''
import json, sys
sys.path.insert(0, "/app")
from types import SimpleNamespace
from backend.services import mt5_bridge as M
from backend.services import destinations_registry as R
from backend.services import pair_admission_controller as A
from backend.services import rejection_service as RS
from backend.services import global_execution_switch as G
from config.settings import asset_class_for

LOT = json.loads(%(lot)s)

def limites(d):
    sante = {}
    try:
        from backend.services import plafond_arbitrage as P
        sante = P._lire_health(d.id, avec_compte=False) or {}
    except Exception:
        sante = {}
    gf = sante.get("garde_fous") or {}
    return {
        "max_correlated_positions": getattr(d, "max_correlated_positions", None),
        "order_cooldown_sec": getattr(d, "order_cooldown_sec", None),
        "max_risque_engage_pct": gf.get("max_risque_engage_pct"),
        "places_par_paire": gf.get("max_open_positions"),
    }

verdicts, lim, libelles, sans = [], {}, {}, set()
for nom in LOT["destinations"]:
    d = R.get(nom)
    if d is None:
        print(json.dumps({"erreur": "destination inconnue: %%s" %% nom,
                          "connues": sorted(R.ids())}))
        raise SystemExit(0)
    lim[nom] = limites(d)
    for i, s in enumerate(LOT["setups"]):
        setup = SimpleNamespace(**s)
        try:
            code = M._check_rejection(setup, d)
        except Exception as e:
            code = "porte_en_erreur:%%s" %% type(e).__name__
        if code and not code.startswith("_"):
            lab = RS.REASON_LABELS_FR.get(code)
            if lab:
                libelles[code] = lab
            else:
                sans.add(code)
        verdicts.append({
            "i": i, "destination": nom, "reason_code": code,
            "classe": asset_class_for(s["pair"]),
            "admission": A.get_current_state(
                s["pair"], direction=s.get("direction"), destination=nom),
        })

det = G.execution_allowed().as_details()
print(json.dumps({
    "fingerprint_running": det.get("fingerprint_running"),
    "rem002_allowed": G.execution_allowed().allowed,
    "rem002_reason": det.get("reason_code"),
    "verdicts": verdicts, "limites": lim,
    "libelles": libelles, "sans_libelle": sorted(sans),
}))
'''


def construire(lot: dict) -> str:
    """Le code Python a executer dans le conteneur, lot embarque en JSON."""
    return _SOURCE % {"lot": json.dumps(json.dumps(lot))}
```

"""La porte avant le pont : juge un lot de setups or, par destination.

Deux moities, comme `or-etat` : un juge PUR teste, et un collecteur impur
non teste. Les verdicts de production viennent d'une charge executee dans le
conteneur ; ce module n'en recopie aucun.

Les quatre contraintes ci-dessous sont un AJOUT de la skill, pas une
description de la production : `_check_rejection(setup, dest)` n'a aucun
parametre « fais comme si ceux-la etaient remplis ». Chaque verdict qu'elles
produisent porte donc `origine: lot`.
"""
from __future__ import annotations

import lot as L

ORIGINE_PRODUCTION = "production"
ORIGINE_LOT = "lot"

_LIMITES_REQUISES = ("max_correlated_positions", "order_cooldown_sec",
                     "max_risque_engage_pct", "places_par_paire")


def cumul_vide() -> dict:
    """L'etat de remplissage simule, vide. Separe par destination."""
    return {"paires": {}, "classes": {}, "risque": {}, "cadence": {}}


def contraintes_lot(setup: dict, destination: str, classe: str,
                    limites: dict, cumul: dict) -> tuple[str | None, dict]:
    """`(reason_code ou None, nouveau_cumul)`. Fail-closed sur toute limite
    illisible : on ne laisse pas passer ce qu'on n'a pas pu verifier."""
    for champ in _LIMITES_REQUISES:
        if limites.get(champ) is None:
            return "limite_illisible", cumul

    paire = setup["pair"]
    cle_p = (destination, paire)
    cle_c = (destination, classe)

    if cumul["paires"].get(cle_p, 0) >= int(limites["places_par_paire"]):
        return "lot_places_par_paire", cumul
    if cumul["classes"].get(cle_c, 0) >= int(limites["max_correlated_positions"]):
        return "lot_exposition_correlee", cumul

    risque = float(setup.get("risk_pct") or 0.0)
    engage = cumul["risque"].get(destination, 0.0)
    if engage + risque > float(limites["max_risque_engage_pct"]):
        return "lot_risque_engage", cumul

    # Le lot n'a pas d'horloge : ses setups sont traites comme SIMULTANES,
    # donc le deuxieme sur la meme paire bloque des que la fenetre existe.
    if int(limites["order_cooldown_sec"]) > 0 and cumul["cadence"].get(cle_p):
        return "lot_cadence", cumul

    neuf = {
        "paires": dict(cumul["paires"], **{cle_p: cumul["paires"].get(cle_p, 0) + 1}),
        "classes": dict(cumul["classes"], **{cle_c: cumul["classes"].get(cle_c, 0) + 1}),
        "risque": dict(cumul["risque"], **{destination: engage + risque}),
        "cadence": dict(cumul["cadence"], **{cle_p: True}),
    }
    return None, neuf
```

def correctif(reason_code: str, setup: dict) -> str:
    """Quoi changer, en nommant la valeur. Jamais « desserrer la regle »."""
    if reason_code.startswith("porte_en_erreur"):

def juger(lot_valide: dict, brut: dict) -> tuple[int, list[str], dict]:
    """`(code, lignes, etat)`. JAMAIS 0 sur une information absente."""
    lignes: list[str] = []
    empreinte_code = brut.get("fingerprint_running")
    if not empreinte_code:
        return 2, ["ECHEC : empreinte_code_illisible -- un verdict calcule "
                   "contre un code inconnu est NUL, rien n'est juge."], {}

    par_couple = {(v["i"], v["destination"]): v
                  for v in brut.get("verdicts") or []}
    limites = brut.get("limites") or {}
    libelles = brut.get("libelles") or {}
    sans_libelle = set(brut.get("sans_libelle") or [])

    lignes.append("  armement : %s (%s)"

                     brut.get("rem002_reason")))
    lignes.append("  ⚠️ les clauses `lot` sont un AJOUT de cette skill, pas un "
                  "comportement de production")
    lignes.append("")

    verdicts: list[dict] = []
    cumul = cumul_vide()
    erreurs: list[str] = []

    for dest in lot_valide["destinations"]:
        for i, setup in enumerate(lot_valide["setups"]):
            vp = par_couple.get((i, dest))
            if vp is None:
                return 2, lignes + [
                    "ECHEC : aucun verdict de production pour setup #%d / %s "
                    "-- le lot n'est pas jugeable." % (i, dest)], {}

            empreinte = L.empreinte_setup(setup)

                    "libelle": libelles.get(reason, reason),
                    "origine": origine,

import pathlib
import sys

import pytest

sys.path.insert(0, str(pathlib.Path(__file__).resolve().parents[1]))
import lot as L  # noqa: E402

prod = pytest.importorskip("backend.services.mt5_bridge",
                           reason="hors conteneur de production")


def _champs_lus_transitivement():
    """Recalcule les champs que `_check_rejection` et ses aides lisent."""
    import ast
    import inspect
    champs, vus, pile = set(), set(), ["_check_rejection"]
    while pile:
        nom = pile.pop()
        if nom in vus:
            continue
        vus.add(nom)
        fn = getattr(prod, nom, None)
        if not callable(fn):
            continue
        try:
            arbre = ast.parse(inspect.getsource(fn))
        except Exception:
            continue
        for n in ast.walk(arbre):
            if (isinstance(n, ast.Attribute) and isinstance(n.value, ast.Name)
                    and n.value.id == "setup"):
                champs.add(n.attr)
            if (isinstance(n, ast.Call) and isinstance(n.func, ast.Name)
                    and n.func.id == "getattr" and len(n.args) > 1
                    and isinstance(n.args[0], ast.Name)
                    and n.args[0].id == "setup"
                    and isinstance(n.args[1], ast.Constant)):
                champs.add(n.args[1].value)
            if isinstance(n, ast.Call) and isinstance(n.func, ast.Name) \
                    and n.func.id.startswith("_"):
                pile.append(n.func.id)
    return champs


def test_la_liste_des_onze_est_celle_que_la_production_lit():
    lus = _champs_lus_transitivement()
    assert lus == set(L.CHAMPS_PORTES), (
        "la production lit %s ; l'empreinte couvre %s. Un champ de plus "
        "garderait vivant un verdict perime."
        % (sorted(lus), sorted(L.CHAMPS_PORTES)))
