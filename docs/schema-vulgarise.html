1. Vue d'ensemble — 4 étages

📡
Collecte
  • Twelve Data prix 5min + 1h, WS
  • ForexFactory news éco
  • COT / F&G positionnement
  • Mataf volatilité
  • DXY / SPX / VIX contexte macro
🧠
Analyse
  • Pattern detector 6 patterns 5min
  • Setup brut entry / SL / TP / R:R
  • Scoring /100 5 facteurs pondérés
  • Macro scoring ×0.75 à ×1.2 + veto
⚖️
Décision
  • Filtre confidence ≥ 75 affichage UI
  • Coaching TAKE / WAIT / SKIP
  • Filtre stars XAU/XAG/WTI/ETH
  • Dedup + safety gates
📤
Distribution
  • WebSocket UI dashboard
  • Telegram push mobile
  • MT5 EA auto-exec broker
  • SQLite log + analytics

+1.6scoaching.py

4. Trois verdicts possibles

✓ TAKE

Score haut, trend alignée, pas de blocker macro. Le radar recommande de prendre le trade.

Push UI Push Telegram Auto-exec MT5

⏳ WAIT

Setup intéressant mais une condition manque (news proche, R:R faible, MTF incertaine).

Push UI Push Telegram

✗ SKIP

Score insuffisant ou veto macro déclenché. Setup loggé pour analyse mais ignoré.

Log SQLite seul
